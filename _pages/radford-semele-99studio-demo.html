Maths home practice

Optional practice families can use at home. Choose the same 99 Club level your child is working on, download a fresh printable activity, or play a school-selected maths game online.

No account is needed. Printable activities create a fresh worksheet or puzzle pack with matching answers each time the parent presses Download.

What this demonstration is showing

  1. The school can use ordinary links/cards, widgets, or a mixture of both.
  2. 99 Club and printable puzzle settings are fixed by the school before sharing.
  3. The school website itself does not need a 99 Studio account or special plug-in.
  4. Nothing changes on the real school website unless an authorised website editor deliberately adds it.

Simple school buttons/cards

The easiest option: ordinary image links made with the school website editor.

Website editor: these need only a normal image/button link. Copy the locked parent-practice URL from Create parent links and attach it to the school's own button/card. No iframe is needed.

99 Club practice

Several levels in one compact panel.

Live widget
Website editor: this is one iframe/embed block. The teacher chooses the visible Club levels and rules in 99 Studio, then copies the generated embed code into the school's normal website editor.

Maths games & printable puzzles

School-selected printable packs and online games.

Live widget
Website editor: this is a separate Maths Games Widget. The school can add several locked printable packs plus a curated set of online games. Printable packs generate fresh puzzles and answers every time.
