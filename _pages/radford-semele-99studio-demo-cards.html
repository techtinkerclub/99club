Visual cards

A more visual school-page layout using ready-made practice cards while keeping each activity as a normal link.

Cards are the visual option. 99 Studio can provide ready-made website-card HTML or downloadable PNG cards. The school attaches the matching practice link and places the cards wherever it wants.

99 Club cards

All 14 levels are shown here using the same card style 99 Studio can generate for school websites.

Printable game-sheet cards

Each card represents one complete locked puzzle-pack setup rather than one fixed PDF.

Online game cards

A few selected games can sit alongside printable practice without exposing the whole game catalogue.

Website setup: use the copied website-card HTML when the CMS allows it, or upload the PNG version and attach the supplied link. The school's own native cards/buttons are also fine.
