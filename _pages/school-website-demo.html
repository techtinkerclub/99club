Buttons and simple links

The most compatible route: ordinary school-website buttons linking to locked 99 Studio practice.

Buttons are the simplest option. The school website creates its own normal buttons and 99 Studio supplies the destination links. No custom HTML or iframe is required.

99 Club practice

All 14 Club levels can be linked separately, so parents choose exactly the level their child is working on.

Post-99 challenges

Printable game sheets

A button can point to a locked school-selected puzzle pack. Every download creates a fresh version with matching answers.

Play online

A school can also link directly to a small curated set of online games.

Website setup: create a normal Button/Link in the school website editor, paste the matching 99 Studio URL, publish, and test it.
Integration example 2 of 3

Visual cards

A more visual school-page layout using ready-made practice cards while keeping each activity as a normal link.

Cards are the visual option. 99 Studio can provide ready-made website-card HTML or downloadable PNG cards. The school attaches the matching practice link and places the cards wherever it wants.

99 Club cards

All 14 levels are shown here using the same card style 99 Studio can generate for school websites.

Post-99 challenges

Printable game-sheet cards

Each card represents one complete locked puzzle-pack setup rather than one fixed PDF.

Online game cards

A few selected games can sit alongside printable practice without exposing the whole game catalogue.

Website setup: use the copied website-card HTML when the CMS allows it, or upload the PNG version and attach the supplied link. The school's own native cards/buttons are also fine.
Integration example 3 of 3

Embedded widgets

The compact option: many school-selected choices presented inside two embedded panels.

Widgets are the compact multi-choice option. One embedded panel can hold many school-selected choices without filling the school page with dozens of separate links.

99 Club Widget

This example contains every Club level: 11–99 plus Bronze, Silver, Gold, Platinum and Diamond.

Website setup: one Embed/HTML/Code block. The school chooses the visible levels and rules before copying the embed.

Maths Games Widget

Three printable puzzle-pack choices plus a small curated Play Online section. The tabs keep the two types of activity separate.

Website setup: a separate Games widget can be changed independently of the 99 Club widget. Printable packs still create fresh PDFs when parents download them.
