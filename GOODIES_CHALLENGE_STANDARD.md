# Goodies challenge standard — paper-first mathematics

Accepted 25 November 2026. Applies to every standard challenge in the whiteboard, standalone manipulatives, worksheet exports, and future widgets.

## Acceptance contract
- State a mathematical question, constraint, or representation task, not instructions for operating a particular UI. A student should have to use mathematical understanding, not merely execute a button that computes the supplied answer.
- Keep teaching/demonstration operations (including splitting and exchanging money) available in Explore, without treating an automatically completed operation as evidence of understanding.
- If an on-screen construction is itself meaningful mathematical evidence (plotting a point, drawing a clock, shading a fraction, etc.), keep it interactive. Export an equivalent blank diagram and explicitly ask the pupil to draw, shade, circle, mark or list a solution.
- The paper version must contain the same mathematical givens, question, units and valid solution set. No reliance on menus, colour alone, animation, live calculations or Check feedback.
- An export must use the original problem, not the teacher's or pupil's modified/revealed answer, and must not leak the answer via an auxiliary label, readout, heading, selected cell or accessibility label.
- Use numeric or choice responses with the shared touchscreen keypad when the question asks for a value. Do not replace reasoning with an automatic exchange or a UI action. Reveal should show the answer and, where useful, a worked representation or explanation.
- Allow different valid constructions when the question does not require a unique representation. Check the mathematical constraints rather than the exact sequence of interactions.
- Test each template with correct, incorrect and incomplete answers, another question, reveal/hide, exit, export before/after reveal, narrow screens and touch input. Inspect actual printed output for enough working space and legibility.

## Initial implementation batch
- Money: exchange templates are calculation questions with fixed evidence, numeric/money entry, worked exchange reveal, and original evidence in paper exports. Construction tasks explicitly ask for drawings or denomination lists in paper.
- Array, multiplication grid, clock, bar model, coordinates, ruler, geoboard, equal groups and percentage construction: paper-specific instructions; blank equal-groups drawing area and fraction bar for percentage shading.
- This batch is not an exhaustive audit. Remaining review: Place Value native activities, classical Abacus and Pascaline, Number Mobile, Number Line, other reasoning and construction questions, custom tasks, export routing and browser/print QA. Review all templates for answer leakage and equivalent solution sets rather than assuming an existing export is valid.
